# Total Recog

GitHub Pages homepage for Total Recog.

The current App Store call-to-action is intentionally disabled. After the app is approved, update `index.html` and replace the disabled CTA with the App Store URL.

Custom domain setup:

1. In GitHub, open the repository settings and enable Pages from the default branch.
2. Add the purchased domain in Pages > Custom domain.
3. Add the matching DNS records in Gabia.
4. Enable Enforce HTTPS after GitHub finishes certificate provisioning.
